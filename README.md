# Bubbly Adventure Club

A fictional-data preview of Bubbly Nursery’s teacher and parent workflows.

Open the site as a static webpage. From the repository root, run `python3 -m http.server --directory public 8000` and visit http://localhost:8000.

The Vercel project should use the repository root and the settings in `vercel.json`. This version serves plain HTML, CSS and JavaScript and requires no package installation, build, or environment variables.

The teacher preview has 15 fictional profiles. Interview drafts remain available during the visit. Save an interview to update the dashboard and portfolio. The parent preview shows Maya’s portfolio and saved interview only. Reloading resets the demo. Use fictional information only.
